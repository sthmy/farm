# Ферма и Биржа

Мем-игра про торговлю картошкой, редкими рыбками, песком, маком и двумя монетами
сомнительного происхождения. Старт — $10.

Фронт статический (GitHub Pages), бэкенд — Cloudflare Worker + D1.
Мобильный первым, десктоп поддержан.

## Как устроен рынок

Цена состоит из двух частей.

**База** считается чистой функцией `basePrice(актив, время)` — пять октав
интерполированного шума. Формула публичная, поэтому график рисуется прямо
в браузере, без запросов к серверу: 60 fps, ноль трафика, кадр за 0.8 мс.

**События** — пампы, обвалы и рагпуллы, которые и решают исход торговли —
генерируются от секретного сида, который живёт только на сервере
(`MARKET_SEED`). Клиент узнаёт о событии, когда оно уже началось, и не может
посчитать будущее, даже открыв исходники. Перк «Инсайдер» официально сдвигает
этот горизонт на 25 секунд вперёд — это единственный легальный способ увидеть
движение заранее.

Сервер считает цену той же функцией в момент сделки, поэтому исполнение
подделать нельзя. Тиковых таблиц нет: база не растёт от торговли.

## Защита

- пароли: PBKDF2-SHA256, 120 000 итераций, индивидуальная соль
- сессии: JWT HS256 на 30 дней, подпись проверяется на каждом запросе
- 8 неудачных входов подряд — блокировка аккаунта на 15 минут
- не больше 5 регистраций в час с одного адреса
- сделки: кулдаун 250 мс и условный `update ... where cash = ?`, поэтому
  два параллельных запроса не потратят одни и те же деньги дважды
- все SQL-запросы параметризованы, имена игроков экранируются при выводе
- позывной приводится к нижнему регистру в JS, а не в SQLite: `lower()`
  в SQLite не понимает кириллицу, из-за чего «Фермер» и «фермер» были бы
  разными игроками

## Экономика

| Актив | Разброс за 6 часов | Роль |
|---|---|---|
| Песок | ×2.2 | тихая гавань |
| Картошка | ×3.0 | стартовый актив |
| Рыбки | ×6.8 | основной риск |
| Мак | ×21 | казино |
| $DUPLODER | ×45 | иксы или ноль |
| $MUSORDROP | ×108 | честное название |

Комиссия 0.4% — без неё скальпинг в одну секунду ломает баланс.
Пособие $5 раз в 4 часа при капитале ниже $2, чтобы игрок не выбывал навсегда.

## Что держит игрока

- **Ежедневный дроп** с серией: $2 в первый день, до $14 на седьмой
- **Три задания в день**: 10 сделок, сделка по мемкоину, $50 оборота
- **Пять апгрейдов навсегда** — от снижения комиссии до пассивного дохода
- **Восемь рангов** от Бомжа с телефона до Хозяина полей
- **Живая лента** чужих сделок и топ-50 по капиталу
- 11 достижений, история сделок, вибро-отклик, установка на домашний экран

## Запуск фронта

Файлы из корня репозитория раздаются как есть: Settings → Pages →
Deploy from a branch → `main` → `/ (root)`.

Пока `config.js` содержит пустой `API_BASE`, игра работает офлайн на
localStorage — удобно проверять интерфейс без бэкенда.

## Запуск бэкенда

```bash
cd worker
npm install
npx wrangler d1 create ferma          # id из вывода вписать в wrangler.toml
npx wrangler d1 execute ferma --remote --file=schema.sql
npx wrangler secret put JWT_SECRET    # длинная случайная строка
npx wrangler secret put MARKET_SEED   # ещё одна, от неё зависят события рынка
npm run deploy
```

Если база создавалась раньше — вместо `schema.sql` выполнить `migrate.sql`.

В `wrangler.toml` указать `ALLOWED_ORIGIN` — адрес GitHub Pages без слэша
на конце. В `config.js` указать адрес воркера.

`npm run deploy` копирует `market.js` в воркер, чтобы формула цены на клиенте
и на сервере не разъехалась. Правится только корневой `market.js`.

## Запросы

Весь обмен идёт через один эндпоинт `/api/sync`: он отдаёт состояние игрока,
прогресс заданий и новые события рынка одним ответом. Отдельных запросов за
ценами, квестами и балансом нет.

- активная вкладка — раз в 20 секунд
- нет действий больше 3 минут — раз в 60 секунд
- вкладка свёрнута — запросов нет вообще, при возврате один догоняющий
- сделка возвращает обновлённый баланс и квесты, так что после неё
  синхронизация не нужна
- лидерборд кэшируется на 30 секунд

Полная история событий за 7 часов весит 7 КБ, инкрементальный ответ — около
50 байт. Активный игрок расходует примерно 180 запросов в час против 500 в
первой версии. Бесплатный лимит Workers — 100 000 в день, это около 550
игроко-часов.

## Тесты

58 автотестов в `worker/test/`, все против настоящей SQLite вместо заглушек:

- `worker.test.mjs` — 32 проверки API: регистрация, дубли ников в разном
  регистре, XSS в имени, подделка токена, покупка на миллиард, отрицательный
  объём, продажа несуществующей позиции, гонка двух параллельных сделок,
  брутфорс, кулдауны, квесты, лидерборд, нормализация путей
- `client.test.mjs` — 14 проверок клиентской логики и офлайн-режима
- `integration.test.mjs` — 11 сквозных: настоящий `store.js` ходит в настоящий
  воркер с базой, проверяется в том числе расхождение цены на экране и цены
  исполнения (сейчас 0.01%)
- `dom.test.mjs` — все элементы, к которым обращается код, есть в разметке

```bash
cd worker && npm test
```
