# Ферма и Биржа

Мем-игра про торговлю картошкой, редкими рыбками, песком и маком. Старт — $10.
Фронт статический (GitHub Pages), бэкенд — Cloudflare Worker + D1.

## Как устроены цены

Цены нигде не хранятся. Есть чистая функция `priceAt(актив, время)` из `market.js`:
5 октав интерполированного шума + редкие событийные всплески. Один и тот же файл
лежит у клиента и у воркера, поэтому:

- график рисуется локально, без запросов к серверу — 60 fps и ноль трафика;
- сервер в момент сделки считает цену сам, подделать её из браузера нельзя;
- у всех игроков рынок одинаковый, без синхронизации и cron-задач;
- база не растёт от тиков — только пользователи, позиции и сделки.

Клиент при входе получает `serverTime` и держит поправку часов, чтобы свеча
на экране совпадала с ценой исполнения.

## Запуск фронта

Фронт лежит в корне репозитория, так его находит Pages. Settings → Pages → Deploy from branch → `main` / `root`.
Пока `config.js` содержит пустой `API_BASE`, игра работает офлайн на localStorage —
удобно проверять UI без бэкенда.

## Запуск бэкенда

```bash
cd worker
npm i
npx wrangler d1 create ferma          # id из вывода вписать в wrangler.toml
npx wrangler d1 execute ferma --remote --file=schema.sql
npx wrangler secret put JWT_SECRET    # любая длинная случайная строка
npm run deploy
```

В `wrangler.toml` поправить `ALLOWED_ORIGIN` на адрес своего GitHub Pages.
Затем в `config.js` указать адрес воркера:

```js
export const API_BASE = 'https://ferma-birzha.ТВОЙ-САБДОМЕН.workers.dev';
```

`npm run deploy` перед публикацией копирует `market.js` в воркер — так формула
цены на клиенте и на сервере не разъезжается. Правишь активы только в `market.js`.

## Что уже внутри

- регистрация и вход: PBKDF2 120k итераций, JWT на 30 дней;
- сделки считаются на сервере, кулдаун 250 мс между ордерами;
- комиссия 0.4% — без неё бесконечный скальпинг ломает экономику;
- пособие $5 раз в 4 часа, если капитал упал ниже $2, чтобы игрок не выбывал навсегда;
- лидерборд по капиталу с учётом открытых позиций;
- лента новостей, привязанная к тем же событиям, что двигают цену;
- достижения, история сделок, вибро-отклик, PWA-манифест.

## Баланс активов

| Актив | Разброс за 6 часов | Роль |
|---|---|---|
| Песок | ×2.2 | тихая гавань |
| Картошка | ×3.0 | стартовый актив |
| Рыбки | ×6.8 | основной риск |
| Мак | ×17.5 | казино |

Меняется одной строкой `vol` и `eventAmp` в `market.js`.

## Следующие шаги
